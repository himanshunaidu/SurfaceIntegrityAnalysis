# Surface Integrity Analysis

Adhoc repository for surface integrity analysis.
Analyses the surface integrity of sidewalks in the iOSPointMapper dataset. 
Provides a streamlit app to label the sidewalk surface integrity.

## References

1. Main Repository

This repository aims to serve the main iOSPointMapper repository:
[iOSPointMapper](https://github.com/TaskarCenterAtUW/iOSPointMapper)

2. iOS Prototype

The research done in this repository is tested and validated using a temporary iOS prototype app:
[iOSSurfaceIntegrityChecker](https://github.com/himanshunaidu/iOSSurfaceIntegrityChecker)
